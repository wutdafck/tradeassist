Instructions to Run Locally with Docker
Install Docker:

Download and install Docker from docker.com.

Clone the Project:

Save the project structure and files to a folder on your machine.

Build the Docker Image:

Open a terminal in the project folder and run:
bash
Copy
docker build -t ai_trading_app .

Run the Docker Container:

Run the container with:
bash
Copy
docker run -p 8501:8501 --env-file .env ai_trading_app

(.env is excluded from the image by .dockerignore, so settings are passed in at run time.
Leave out --env-file if you have no .env; public market data still works.)

Access the App:
Open your browser and go to http://localhost:8501.
